# 메이킹 탭 수동 사용법

G2~G5 파이프라인이 자동으로 만들어주지 않는 컷타입(BROLL/CAPCUT/GRAPHIC)의 실제 영상을 직접 제작하는 탭입니다. 편집메타 탭 바로 앞에 있습니다.

## 0. 전체 흐름 한눈에 보기

 
1. (선택) 소스 검색에서 참고/원본 소재 다운로드

2. BROLL 컷 → 화면 녹화 → 자동 트림/스케일 → cut_NN.mp4 확정

3. CAPCUT 컷 → CapCut 화면 녹화 → 자동 트림/스케일 → cut_NN.mp4 확정

4. GRAPHIC 컷 → HTML 카드 편집 → 캡처 → cut_NN.mp4 확정

5. G5-M 조립 → 위에서 확정한 cut_NN.mp4 + 기존 YEORI 영상을 컷 순서대로 이어붙여  ep{N}_making.mp4 생성
 

모든 컷타입의 "확정 파일"은 종류와 무관하게 전부 `downloads/video/ep{N}/cut_{2자리번호}.mp4` 한곳에 모입니다. 
그래서 5번(G5-M)이 컷타입을 신경 안 쓰고 번호 순서대로 이어붙이기만 하면 됩니다.

 13

## 1. 소스 검색 (Pexels)

BROLL/CAPCUT에 쓸 참고 영상·이미지를 검색해서 바로 받아두는 보조 기능입니다. 
녹화 자체와는 별개 — 검색 결과를 다운로드해두면 `downloads/making/ep{N}/source/` 에 저장되고, 그걸 화면에 띄운 뒤 아래 3~4번 녹화로 캡처하는 식으로 씁니다.

1. **검색어** 입력 (영어가 잘 나옵니다. 예: `slot machine lever`)

2. **유형**(전체/영상/이미지), **방향**(세로우선/가로/전체) 선택

3. **대상 컷** 드롭다운에서 이 소재를 쓸 컷 번호 선택 (다운로드 경로에만 쓰임, 자동 재생 연결은 안 됨)

4. 결과 카드에서 **다운로드** 클릭 → `저장됨 ✅` 확인

5. Pexels 무료 소재라 저작자 표시(하단 "Photos provided by Pexels")는 그대로 두면 됩니다.



## 2. BROLL 컷 — 화면 녹화

**대상:** 컷타입이 `BROLL`인 컷만 목록에 뜹니다.

1. **BROLL 컷 목록**에서 원하는 컷(`#번호`) 클릭 → 아래에 `#N 녹화 설정` 패널이 펼쳐짐.

2. **URL(선택)**: 녹화할 웹페이지 주소가 있으면 입력 후 "열기"로 새 탭에 띄움. 로컬 파일(내 PC 영상 등)을 소스로 쓸 땐 이 필드는 비워두고, 
   파일을 직접 미디어 플레이어 등으로 먼저 열어두면 됩니다.

3. **녹화 품질**: low/medium/high (medium 기본 추천)

4. **녹화 영역** ⚠️ 중요:
   - **전체화면** — 화면에 보이는 전부를 녹화. 다만 그 순간 다른 창(예: 이 채팅창, VS Code 등)이 위로 튀어 오르면 그게 그대로 찍힙니다. 
     녹화 시작 직전에 목표 창이 실제로 최상단에 있는지 반드시 눈으로 확인하세요.
   - **특정영역** — x/y/w/h 좌표로 지정한 영역만 잘라서 녹화. **그 좌표에 목표 창이 물리적으로 있기만 하면 다른 창에 가려도(포커스가 다른 곳에 있어도) 
     항상 그 자리를 그대로 찍습니다.** 여러 창을 오가며 조작해야 하거나 다중 모니터 환경이면 이쪽이 훨씬 안전합니다(2026-08-21 라이브 테스트로 확인).

   - 좌표를 모르면: 목표 창을 원하는 위치에 띄워두고, 작업표시줄이나 Alt+Tab에서 그 창 크기/위치를 어림잡아 x(왼쪽에서부터)/y(위에서부터)/w(너비)/h(높이)를 입력하면 됩니다.
5. **목표 길이(초) / 트림 위치**: 최종적으로 남길 길이와, 녹화본에서 어느 쪽을 자를지(끝에서부터=앞부분을 남김 / 처음부터=뒷부분을 남김)
6. **녹화 시작** 클릭 → 목표 화면 조작(스크롤 등 실제로 담고 싶은 동작) → **🔴 녹화 중... 중지** 클릭
7. 자동으로 트림 + 1080×1920 스케일/크롭 + 인코딩까지 끝나고 결과가 뜸:
   - **최종**: `downloads/video/ep{N}/cut_{NN}.mp4` — 이게 실제 컷 영상으로 확정된 파일
   - **원본(raw, 보관됨)**: `downloads/making/ep{N}/broll_raw_cut{NN}.mp4` — 편집 전 원본, 나중에 다시 트림하고 싶을 때 대비해 남겨둠

 

## 3. CAPCUT 컷 — CapCut 편집 화면 녹화

**대상:** 컷타입이 `CAPCUT`인 컷만 목록에 뜹니다. **CapCut 데스크톱 앱을 먼저 켜두세요.**

1. **CAPCUT 컷 목록**에서 컷 선택

2. **CapCut 상태 확인** 클릭 → `✅ 실행 중 — CapCut (PID ..., 창 W×H)` 뜨면 준비 완료. `⚠️ CapCut을 먼저 실행해주세요` 가 뜨면 CapCut을 켜고 다시 확인

3. 영역은 CapCut 창을 자동으로 찾아서 그 부분만 잘라 녹화합니다(사람이 좌표 입력 불필요) — 
   여러 모니터를 쓰는 이 PC 환경에서도 정확히 보정되도록 되어 있어서, CapCut 창이 화면 어디에 있든 다른 창에 가려도 항상 정확히 그 부분만 찍힙니다.

4. **목표 길이(초) / 트림 위치** 설정 (BROLL과 동일)

5. **녹화 시작** → CapCut에서 실제로 편집 작업(타임라인 배치, 자막 추가, 화면분할 등) 진행 → **🔴 녹화 중... 중지**

6. 결과: 최종 `downloads/video/ep{N}/cut_{NN}.mp4`, 원본 `downloads/making/ep{N}/capcut_cut{N}_raw.mp4`



## 4. GRAPHIC 컷 — HTML 그래픽 카드 캡처

**대상:** 컷타입이 `GRAPHIC`인 컷만 목록에 뜹니다. 화면 녹화가 아니라 HTML로 만든 정지 그래픽을 이미지→영상으로 변환합니다.

1. **GRAPHIC 컷 목록**에서 컷 선택 → 해당 컷의 나레이션/장면 설명이 자동으로 채워진 HTML 템플릿이 나타남(검정 배경, 1080×1920, 중앙 정렬 텍스트)

2. **HTML 소스** 텍스트박스에서 직접 수정 가능(글자 크기, 색, 문구 등 자유롭게)

3. **길이(초)** 입력 → **미리보기**로 실제 모양 확인

4. 마음에 들면 **캡처 & 저장** 클릭

5. 결과: 이미지 `downloads/video/ep{N}/cut_{NN}_graphic.png` + 영상 `downloads/video/ep{N}/cut_{NN}.mp4`



## 5. 메이킹 필름 조립 (G5-M)

BROLL/CAPCUT/GRAPHIC로 확정한 영상 + 기존 YEORI 영상을 컷 번호 순서 그대로 이어붙여 하나의 필름으로 만듭니다.

1. 맨 아래 **🎬 메이킹 필름 조립** 클릭

2. `downloads/video/ep{N}/cut_{NN}.mp4`가 있는 컷은 포함, 없는 컷은 자동으로 건너뜀(스킵된 컷 번호도 결과에 표시됨 — 
    아직 안 만든 컷이 있어도 조립 자체는 막히지 않음)

3. 결과: `downloads/making/ep{N}/ep{N}_making.mp4`

 

## 참고: 결과 파일 경로 정리

| 무엇                                     | 경로                                                                   |
 
| 확정된 컷 영상(전체 타입 공통) |  `downloads/video/ep{N}/cut_{NN}.mp4`                   
| GRAPHIC 캡처 원본 이미지      |  `downloads/video/ep{N}/cut_{NN}_graphic.png`        
| BROLL 녹화 원본(raw)             |  `downloads/making/ep{N}/broll_raw_cut{NN}.mp4`     
| CAPCUT 녹화 원본(raw)          |  `downloads/making/ep{N}/capcut_cut{N}_raw.mp4`    
| Pexels 다운로드 소재              |  `downloads/making/ep{N}/source/{filename}`           
| 최종 메이킹 필름                   |  `downloads/making/ep{N}/ep{N}_making.mp4`         



## 알아두면 좋은 점

- **BROLL 전체화면 녹화는 항상 시작 직전에 목표 창이 진짜 최상단인지 눈으로 확인하세요.** 
  다른 창이 잠깐이라도 튀어 오르면 그게 찍힙니다. 
  확신이 없으면 "특정영역"을 쓰는 게 안전합니다.

- raw 원본은 지우지 않고 계속 쌓입니다 — 
  나중에 다른 길이/트림 위치로 다시 편집하고 싶으면 raw 파일을 기준으로 수동 재작업하면 됩니다.

- G5-M은 몇 번이든 다시 눌러도 됩니다(덮어쓰기) — 
  컷을 하나 더 만들고 나서 다시 조립하면 새로 포함됩니다.

- 소스 검색(Pexels)의 "대상 컷"은 파일 저장 경로만 결정할 뿐, 녹화 화면과 자동으로 연결되지는 않습니다 — 
  받은 파일을 직접 열어서 화면에 띄운 뒤 BROLL/CAPCUT 녹화로 캡처하는 별도 단계가 필요합니다.
