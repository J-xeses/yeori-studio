처음 한 번만 하는 설정

  1. 📥 담기 버튼 설치 — 레퍼런스 보드 상단의 노란 📥 담기 버튼을 크롬 북마크바로 끌어다 놓기. (클릭이 아니라 드래그)
    ⚠️ 이 버튼은 설치할 때의 사본이라, Claude가 담기 기능을 고쳤다고 하면 기존 북마크를 지우고 다시 끌어다 놓아야 반영됩니다.
  2. 핀터레스트 보드 3곳 — 연출 기법모션 그래픽주목할 영상 을 공개로 두기(비밀 보드는 자동 수집 안 됨).
  3. 유튜브 재생목록 — 벤치마킹 영상 을 일부공개로 두고, 그 재생목록 화면에서 📥 를 한 번 누르기 → 이후 자동 등록됨.
  4. 인스타 저장 컬렉션 — 벤치마킹용 컬렉션 하나(지정: jun9320027 / 저장됨 / 벤치마킹). 따로 설정할 건 없음.

평소 쓰는 법

📌 핀터레스트

  1. 찾기: 레퍼런스 보드 상단 검색칸에 키워드 → 📌 핀터레스트 열기(또는 Enter) → 새 크롬 창에 검색 결과가 열림. 검색 결과는 보여주기만 하고 자동으로 담지 않습니다.
  2. 마음에 드는 핀을 대상 보드 3곳 중 하나에 저장 → 3시간 안에 자동으로 수집함에 들어옴.
  3. 지금 바로 넣고 싶으면: 그 핀 화면이나 보드 화면에서 📥 클릭 → 즉시.

▶️ 유튜브

  1. 영상 아래 저장 → '벤치마킹 영상' 재생목록에 넣기 → 3시간 안에 자동.
  2. 지금 바로: 재생목록 화면이나 영상 화면에서 📥.

📸 인스타그램

  1. 게시물 저장 → 벤치마킹 컬렉션에 넣기. (인스타는 자동 수집 없음 — 로그인 필요 + 자동 크롤링은 하지 않는 원칙)
  2. 모아뒀다가 컬렉션 화면을 끝까지 스크롤한 뒤 📥 → 화면에 보이는 게시물이 전부 담김(이미 담긴 건 자동으로 건너뜀).

📥 를 누르면 작은 새 창이 떠서 "N개 중 새로 M개 담았습니다"를 보여주고 저절로 닫힙니다. 정리는 1~2분 뒤 끝납니다.

헷갈릴 때

보드/재생목록에 저장했는데 수집함에 안 보여요

자동 수집은 3시간마다입니다. 바로 보려면 레퍼런스 보드 수집함의 🔄 가져오기, 운영실 수집함 칸의 🔄 지금 가져오기·정리, 또는 C:\yeori-studio\collect.bat 더블클릭. 그래도 없으면 → 보드가 비밀이거나 재생목록이 비공개인지 확인(그럼 📥 로만 들어옴).

📥 를 눌렀는데 아무 창도 안 떠요

① 크롬이 팝업을 막았는지 주소창 오른쪽 아이콘 확인 → 허용. ② 스튜디오 서버(:3001)가 꺼져 있으면 실패 — start_yeori.bat 실행. ③ "담을 항목을 못 찾았습니다"가 뜨면 목록이 아직 덜 불러와진 것 → 스크롤 후 다시.

"정보 부족(직접 확인 필요)"이라고 나와요

제목·설명이 없는 핀입니다. 썸네일이 있으면 AI가 이미지를 보고 분류하지만, 영상 핀은 서버에서 썸네일조차 못 읽는 경우가 있어 아무 정보가 없으면 자동으로 숨깁니다. 꼭 필요한 영상 핀은 그 핀 화면에서 📥 하거나 ref-grab.bat에 링크+메모로 넣으세요.

퍼블리싱 탭에 키워드 후보 칩이 안 보여요

후보는 인스타·유튜브 자료에서만 뽑습니다. 그쪽 자료가 없거나, 후보가 이미 전부 등록돼 있으면 칩이 안 보입니다.

분류(용도/기법)가 이상해요

레퍼런스로 등록한 뒤라면 ref-grab.bat로 같은 링크를 넣으면서 메모를 붙이면 메모 기준으로 다시 잡힙니다. 분류표 자체를 바꾸고 싶으면 Claude에게 말하면 됩니다(app/server/lib/refTaxonomy.js).

스토리 아카이브에 원치 않는 '자동수집' 항목이 생겼어요

그 항목의 삭제 버튼으로 지우면 됩니다. 같은 자료가 다시 추가되지는 않습니다.

비용은 얼마나 드나요?

정리는 Claude Haiku로 8개씩 묶어 한 번 — 수십 개 정리에 몇십 원 수준. 웹 검색은 쓰지 않습니다. 이미 정리된 자료는 다시 보내지 않습니다.
