## 재개 문구 (같은 세션에)
```
Bash가 다시 되면 순서대로 해 줘(같은 명령 3번 연속 실패하면 즉시 멈추고 보고):
1) git status 와 git diff --stat 결과를 먼저 보여 줘. 특히 app/code_generator_v1.html 이 실제로 변경됐는지 확인 — 편집 패널에는 2개 파일(pipeline-selftest.js, proxy.js)만 보였어.
2) code_generator_v1.html 변경이 없거나 일부만 있으면, 지시문의 ①~⑤ 에피소드 탭 작업을 마저 해 줘.
3) 검증(인라인 스크립트 new Function 파싱, node --check proxy.js, 파서 단위 테스트)을 돌리고 결과를 보여 줘.
4) master에서 codigen-brief-r4 브랜치를 만들어 커밋·푸시(master에는 절대 푸시 금지).
```
