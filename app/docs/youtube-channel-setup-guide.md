# 서여리 유튜브 채널 개설 실행 가이드 (2026-10-18)

실제 채널 개설 당일 보면서 따라 하는 실행 문서. 전략/기획 배경은 [[project_roadmap_2026_09]]·`!Ahn\Corporation\...\05. 유튜브 분석\` 자료를 참고했고,
여기 적힌 각 항목은 `localhost:3001/youtube-ops` ⚙️계정·크리에이터 설정 탭의 체크리스트와 1:1로 대응한다 — 여기서 "어떻게" 하는지 보고, 운영실에서 체크만 하면 됨.

## 0. 출발점 (지금 상태)

- `downloads/seoyeori/YU/_account/ops.json` 기준: `accountCreated: false` — 아직 채널 자체가 없음. 오늘 밤이 진짜 첫 단계.
- 채널명은 이미 `"Seoyeori 서여리"`로 예약돼 있음(인스타 `@seoyeori.kr`와 브랜드 통일). 핸들(@)은 아직 미정 — 인스타와 동일하게 `@seoyeori.kr` 또는 `@seoyeori_kr`을 1순위로 시도.
- 채널 소개(description)·카테고리도 아직 빈 값 — 이 문서 §3에서 바로 채워서 들어가면 됨.

## 1. 계정 유형부터 결정 — 개인 계정이 아니라 "브랜드 계정"으로

구글 계정으로 바로 채널을 만들면 **개인 계정**이 되는데, 이러면:
- 운영자(성준님) 개인 구글 프로필과 채널이 묶여서, 나중에 다른 사람에게 관리자 권한을 주거나 법인/협업 전환할 때 분리가 번거로움
- 채널 이름이 구글 계정 실명과 섞여 보일 수 있음

**브랜드 계정**으로 만들면:
- 채널이 독립된 개체가 되어 여러 구글 계정에 관리자/편집자 권한을 나눠줄 수 있음
- 나중에 법인명의 전환, 팀원 추가가 쉬움
- 유튜브 스튜디오에서 "채널 만들기" 시 "브랜드 계정 만들기"를 선택하면 됨(개인 이름이 아닌 "Seoyeori 서여리"로 입력)

**→ 반드시 브랜드 계정으로 생성할 것.**

## 2. 채널 생성 단계 (구글 계정 → 채널 만들기)

1. `youtube.com` 접속 → 우측 상단 프로필 아이콘 → **"채널 만들기"**
2. 이름/사진 선택 화면에서 **"맞춤 이름 사용"** 선택 → 브랜드 계정으로 분기
3. 채널명(브랜드 계정 이름): `Seoyeori 서여리` 입력
4. 생성 완료 후 바로 콘텐츠를 올리지 말 것 — **배너·프로필·설명·핸들을 먼저 다 채운 뒤에 첫 영상** (첫인상이 구독 전환율에 직결)

## 3. 채널 아트·프로필·설명·핸들 세팅

| 항목 | 스펙/내용 |
|---|---|
| 프로필 사진 | 800×800px, 서여리 얼굴 클로즈업 — `downloads/seoyeori/YU/_account/profile/`에 넣고 운영실에서 새로고침하면 선택 가능 |
| 채널 아트(배너) | 2560×1440px, 핵심 메시지 + (정하면) 업로드 요일 명시 |
| 핸들(@) | `seoyeori.kr` 또는 `seoyeori_kr` — 인스타와 동일 핸들 우선 시도, 선점 안 되면 운영실 설정값도 같이 맞춰서 저장 |
| 카테고리 | People & Blogs (운영실 기본값 — 경쟁 채널 카테고리는 vidiQ 확장으로 확인 가능, §4-③ 참고) |
| 채널 설명 | **첫 2줄이 검색 노출에 그대로 쓰임** — 키워드 포함해서 작성. AI 캐릭터라는 점을 밝히는 문구 포함(채널 자체 설명 + 매 영상 "변조/합성 콘텐츠" 라벨 둘 다 필요, §5) |
| 워터마크 | 우측 하단 구독 유도용 — 로고/아이콘 준비되면 추가 |
| SNS 연동 | 인스타(@seoyeori.kr) 링크 연결 |

**이름 관련 주의**: 채널명에 숫자·특수문자 넣지 말 것 — 검색 SEO에 불리함.

## 4. 유튜브 스튜디오 설정 8가지 (정확한 메뉴 경로)

성준님이 사전 조사한 메뉴 경로 그대로. 전부 운영실 체크리스트의 "업로드·설정 8가지"와 대응함.

1. **영상 비공개 예열** — 유튜브 스튜디오 → 설정 → 업로드 기본 설정 → 공개 상태 "비공개"로. 업로드 후 24시간 그대로 둬서 알고리즘이 먼저 분석하게 하고, 24시간 뒤 "공개"로 전환.
2. **홈탭 레이아웃** — 유튜브 스튜디오 → 맞춤설정(요술봉 아이콘) → 홈탭 → 레이아웃을 **인기 동영상 → 게시물 → 동영상 → 재생목록** 순서로.
3. **카테고리 설정(경쟁 채널 몰래 확인)** — vidiQ 크롬 확장 설치 → "View Channel Stats" 버튼 → 경쟁 채널들이 어떤 카테고리를 쓰는지 참고.
4. **AI 콘텐츠 표시** — 영상 업로드 과정 중 "변경된 콘텐츠" 항목에서 체크(유튜브가 "AI 사용 자체는 불이익 없다"고 공식 해명함 — 안 켜는 게 리스크, 켜는 게 안전).
5. **업로드 시점 최적화** — vidiQ의 Suggestions에서 실시간 피크타임 확인 → 피크 2~3시간 전, **정시를 피해 10~20분 전** 업로드(정시엔 여러 채널 업로드가 겹쳐 묻힐 수 있음).
6. **채널 키워드** — 크롬 새 시크릿 창(검색기록으로 알고리즘 오염 방지) → 유튜브에서 타깃 키워드 검색해 실제 쓰이는 검색어 확인 → 설정 → 채널 → 키워드란에 입력.
7. **자동챕터 끄기** — 유튜브 스튜디오 → 설정 → 업로드 기본설정 → 고급설정 → "자동챕터 및 주요 순간 허용" 끄기. 수동으로 타임스탬프 찍어서 키워드 기반 챕터 직접 구성(정확도+알고리즘 신호 둘 다 이득).
8. **해시태그** — 설명란에 3~6개(너무 많으면 스팸 취급 위험). 해시태그와 별개로 태그란에 15~20개(정확한 키워드 → 관련 키워드 → 넓은 카테고리 순)까지 채우면 더 좋음. 경쟁 채널 해시태그도 vidiQ로 확인 가능.

## 5. 보안·수익화 체크

- **2단계 인증** 반드시 켤 것(계정 탈취 방지, 이후 YPP 심사에서도 체크됨).
- **YPP(수익창출) 2단계 조건** (운영실 §목표·대시보드에서 실시간 게이지 추적):
  - 1단계(멤버십·슈퍼챗): 구독 500 + 최근 90일 공개 영상 3개 + (연 시청 3,000h 또는 쇼츠 조회수 300만/90일)
  - 2단계(AdSense, 실질 목표): 구독 1,000 + (연 시청 4,000h 또는 쇼츠 1,000만/90일)
  - **2027-02-01부터 신규 가입 기준이 2배로 강화**(8,000h / 2,000만) — 그 전에 2단계 가입을 끝내는 게 핵심 데드라인.

## 6. 첫 영상 3개가 채널 방향을 결정한다

알고리즘이 초기 시청자 반응으로 채널 카테고리를 분류하기 때문에, 첫 3개가 중요함:
1. **채널 소개 + 가장 자신 있는 주제** (10분 내외 또는 숏츠)
2. **검색 유입용 How-to 콘텐츠**
3. **공감형 스토리텔링**

이미 서여리 쪽은 IG_R04(채널소개), SF_E01~E12(스토리텔링 숏츠) 재고가 충분히 쌓여있어 — 운영실 "콘텐츠 파이프라인 현황" 표에서 바로 골라 순서만 정하면 됨.

**썸네일 원칙**: 얼굴 클로즈업 + 감정 표현이 CTR 최고 / 텍스트 3단어 이내, 큰 폰트 / 색상 대비 강하게(어두운 배경+밝은 텍스트). — 퍼블리싱 탭 ①썸네일 섹션으로 바로 제작.
