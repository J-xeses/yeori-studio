## 1. P1-03 주제 × 시나리오
**성준님**: 스튜디오·에이전트와 일관된 항목으로 정리 필요 / 주제=첫 줄, 시나리오=둘째 줄로 충분한지 / 중복 선택 필요 여부 / 빨강+초록 선택 표시가 초록 계열 UI에서 불균형.
**조사**
- 주제 5개(PSY 심리·SOC 사회·LIF 일상·REL 관계·TRD 트렌드), 시나리오 4개(MYS·DOC·EDU·ENT)가 **코드에 고정**. 스튜디오 마스터 코드(`SP:IN.HM.TZ_NT…`, `PL:IG_RL`), 트렌드 레이더·후보 풀 주제와 **연결되지 않음**.
- 둘 다 **단일 선택**(`state[key] === code`).
- 색: 주제 = `.pill.on`(teal 초록), 시나리오 = `.pill.on-o`(scarlet 빨강) → 불균형의 직접 원인.
- 04 에피소드 ID 자동생성 = `${플랫폼}_E${번호}_${주제}` → `SF_E01_PSY`. 지금 규칙(IG_R07, LF_T01)과 다름.

## 권장 순서
1. **기반(데이터 연결)**: 사이드바·DEMO_CUTS·주제/시나리오를 실제 데이터(후보 풀·스튜디오 에피소드·코드 규칙)에 연결. 이게 안 되면 나머지 UI 개선이 예시 위에서 도는 셈.
2. **구조(번호·Phase)**: 탭별 Phase 재정의, 번호는 탭 안에서만 → 패키지 = "생성"과 "스튜디오 전달" 두 단계로 분리·명명.
3. **시각(색·히트맵)**: 선택 표시 단일 계열, 워크플로우 셀 히트맵(상태 + 값 강도).
4. **CA_BANK 아카데미**: characters.json 과 단일화 후 설계.
