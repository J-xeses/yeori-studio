# 서여리 능동형 감정이입 대응 시스템 — 설계안 v0.1 (2026-09-27)

> 성준님 요청: "서여리가 운영하는 감성이 최대한 표출되어야 한다."
> 근거 자료: 초창기 페르소나(2026-04-19), 캐릭터 연출 인사이트 모음(0524), 콘텐츠 컨셉 정의,
> e-03 홈카페 브이로그 대참사, e-05 핫플 갔다가 폰 내린 날, IG_R04·R05·R06 대본.

## 0. 한 줄 정의
**서여리가 "스스로 느끼고 먼저 말을 거는" 운영 주체가 되도록**, 채널에서 일어나는 신호(날씨·날짜·성과·댓글·지난 에피소드)를
서여리의 감정 상태로 바꾸고, 그 감정으로 **대본·캡션·스토리·댓글 답장**을 만들어 사람(성준님)이 최종 승인하는 체계.

## 1. 서여리의 감성 코어 (한 곳에서 관리하는 원본)
`characters.json → yeori.persona` 에 구조화해 두고, 대본·캡션·답장 생성이 모두 여기서 읽는다.

| 축 | 내용(자료에서 추출) |
|---|---|
| 두 얼굴 | **카메라 앞**: 밝고 에너지 넘침, 과하게 완벽한 인플루언서 모드 · **카메라 밖**: 차분·진중, 불안정한 자신감, 누군가에게 기대고 싶음 |
| 핵심 반전 | 완벽해 보이는 모습 → 들키는 진짜 모습(홈카페: "커피 머신 한 번도 제대로 써본 적 없어") → 당당한 인정("It's called creative direction, okay?") |
| 말버릇 | "음…", "그러니까…", "근데 있잖아", 영어 단어 자연스럽게 섞기, 고백하듯 낮아지는 톤 |
| 좋아함 | 혼자 카페, 비 오는 날 창가, 오래된 책, 클래식, 진심 어린 대화, 따뜻한 차 |
| 싫어함 | 피상적 관계, 약점 드러내기, 과도한 기대, SNS 압박, 혼자가 너무 길어질 때 |
| 포지션 | **감성 큐레이터** — 전문가가 아니라, 사소한 일상·K-트렌드를 서여리의 시선으로 걸러 "나만 그런 게 아니었네?"로 연결 |
| 연출 서명 | 사건→감정 변화→선택 3막, **여운 엔딩**(대사 뒤 2~3초 침묵·시선), BGM 끊김으로 현장감, 상징(하이힐=페르소나/맨발=진짜 여리) |
| 관계 | 지아(절친·리액션), 지유(발랄한 분위기 메이커), 가족(부모·남자형제 — 소재 창고 e-00) |

⚠️ **정리가 필요한 설정 충돌**: 초창기 페르소나는 "수십만 팔로워를 가진 인기 인플루언서"인데, 실제 채널은 막 시작했고
R04 에서 "저 사실 이 채널 AI로 만들어요"를 공개했다. → **캐논(공식 설정)** 결정 필요(§6 결정 1).

## 2. 감정 엔진 — "오늘의 여리"
매일 한 번(토큰 0 규칙 + 필요 시 LLM 1회) 서여리의 **감정 상태**를 정한다.

```
신호(입력)                               → 감정 상태(출력)
- 날씨·계절·요일(비/첫눈/월요일/금요일 밤)   mood   : 설렘·차분·쓸쓸·뿌듯·장난·지침 …
- 기념일·시즌(추석, 수능, 크리스마스)        mask   : 0(진짜 여리) ~ 1(카메라 앞 완벽 모드)
- 채널 성과(첫 팔로워, 저장·공유 급증, 조회 저조)  energy : 낮음~높음
- 댓글·DM 분위기(응원/장난/걱정/악플)         topic  : 오늘 마음에 걸린 것 한 줄
- 지난 에피소드 사건(흑역사 공개됨 등)         callback: 이어서 말할 지난 사건
```
- **규칙 우선(토큰 0)**: 신호→감정 매핑 표(예: 비 → 차분/창가, 금요일 밤 → 쓸쓸, 첫 팔로워 → 뿌듯·수줍음, 저장 급증 → 감동, 악플 → 상처받지만 담담).
- 감정 상태는 `downloads/state/yeori-mood.json` 에 날짜별로 남긴다 → 연속성(어제 쓸쓸했으면 오늘 "어제는 좀 그랬는데…").

## 3. 능동 대응 — 서여리가 먼저 하는 일
| 트리거 | 서여리의 반응(초안) | 승인 |
|---|---|---|
| 게시 직후 | 캡션 끝 한 줄을 오늘 감정으로(예: 쓸쓸한 날 → "오늘은 좀 조용히 있고 싶었어요") | 사람 |
| 첫 팔로워·팔로워 이정표 | 스토리 문구 "음… 누가 저를 팔로우했어요. 진짜로요?" | 사람 |
| 저장·공유 급증 게시물 | 감사 스토리 + 다음 에피소드 소재 제안 | 사람 |
| 댓글 | **댓글 답장 초안**(mask 수준에 맞춘 말투, 반말/존댓말 규칙, 말버릇 1개 이하) | 사람(처음엔 전부), 나중에 칭찬·이모지 댓글만 자동 |
| 조회 저조 | 서여리 톤의 자기 고백형 다음 훅 제안("솔직히 말할게…") | 사람 |
| 지난 사건 | 콜백 거리 제안(흑역사 → 다음 편에서 지유에게 복수) | 사람 |
| 대본 작성 시 | 감성 코어 체크리스트 자동 적용(두 얼굴 반전·여운 엔딩·말버릇·상징) | 대본 G1 |

## 4. 안전선
- AI 표시 일관성: 서여리는 **AI 크리에이터임을 숨기지 않는다**(R04 캐논). "진짜 사람인 척" 답장 금지.
- 과도한 친밀감·연애 암시·개인 연락 유도 금지, 미성년 대상 대화 주의, 의료·금융 조언 금지.
- 악플에는 대응하지 않거나 담담한 한 줄만. 논쟁 금지.
- **게시·답장은 항상 사람 승인 후**(초기). 자동 게시는 성준님이 범위를 정한 뒤에만.
- 토큰 예산: 감정 엔진·트리거는 규칙(토큰 0), LLM 은 초안 생성에만 하루 상한(예: 10회) — [[주간 사용량 규칙]].

## 5. 구현 단계 (작게, 검증하며)
| 단계 | 내용 | 비용 |
|---|---|---|
| **P1 감성 코어** | persona 구조화(characters.json), 대본 체크리스트(selftest 로 대본 검사: 여운 엔딩·반전·말버릇) | 토큰 0 |
| **P2 오늘의 여리** | 신호 수집(날씨 API·달력·인스타 성과) → 감정 상태 JSON, 운영실에 "오늘의 여리" 카드 | 토큰 0 |
| **P3 캡션·스토리 초안** | 게시·이정표 트리거 → 초안 큐(운영실 승인 버튼) | LLM 소량 |
| **P4 댓글 답장** | Instagram API 댓글 읽기(권한 이미 추가됨) → 답장 초안 → 승인 → 게시 | LLM 소량 |
| **P5 콜백·연속성** | 에피소드 사건 원장(누가 무엇을 했나) → 다음 대본 제안에 반영 | 토큰 0~소량 |
