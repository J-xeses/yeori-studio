## 2. "컷의 실제 쓸 파일" 규칙 (한 곳: `mediaPaths.js` `pickCutSource`)

1. `cut_NN_subtitle.mp4`, `cut_NN_overlay.mp4` 중 **원본 `cut_NN.mp4`보다 나중에 만든 것**만 유효
2. 유효한 것이 둘이면 더 나중에 만든 쪽
3. 없으면 원본 `cut_NN.mp4`

이 규칙을 쓰는 곳: 릴스 최종본, 메이킹 필름 조립, 컷별 판단 미리보기, 메이킹 탭 "이 컷의 최종 결과", 영상 만들기 탭 "최종 합성본".
파생본을 쓴 컷과 자동 텍스트카드 컷은 최종본에서 자막을 다시 굽지 않는다.

## 3. 같은 파일을 여러 곳이 덮어쓰는 지점 (오류가 반복되던 원인)

`05_video/cut_NN.mp4` 를 쓰는 버튼:
- 메이킹: 제작 실행(텍스트카드/목업 캡처), 사진 시퀀스 확정, 이 소스로 컷 제작, BROLL·녹화
- 영상 만들기: 클립 합성, 완성본 바로 업로드, PIP 합성

보호 장치(2026-10-07): 덮어쓰기 직전본을 `05_video/_manual_work/cut_NN_prev.mp4` 로 1벌 보관, 텍스트카드로 기존 컷을 덮을 때와 메이킹 탭 결과를 클립 합성으로 덮을 때 한 번 더 확인.

## 4. 자막이 들어가는 길 세 가지

| 방식 | 어디서 설정 | 어디에 구워지나 |
|---|---|---|
| 최종본 자동 자막 | 대본 자막(CP) + 영상 만들기 탭(문구·크기·세로 위치·컷별 시작 초) | 릴스 최종본 생성 시 |
| 자막 효과(모션 자막) | 메이킹 컷 카드 ③ | 그 컷의 `_subtitle.mp4` (그 컷은 자동 자막 생략) |
| 말풍선·손글씨 | 메이킹 컷 카드 ② | 그 컷의 `_overlay.mp4` (그 컷은 자동 자막 생략) |

## 5. 나레이션이 들어가는 길 두 가지 (겹치지 않게 주의)

- 컷의 나레이션 칸에 문구가 있고 `cut_NN_nr.mp3`(또는 대사 없는 컷의 `cut_NN.mp3`)가 있으면 → 최종본이 컷 시작 +0.3초에 믹스
- 사진 시퀀스에서 나레이션을 골라 컷 영상에 직접 합친 경우 → 컷 자체 소리로 들어감

정식 절차는 첫 번째다: 컷 나레이션 칸 → TTS 탭에서 생성·합치기(`cut_NN.mp3` 저장)·G3 승인 → 최종본이 믹스.
대본에 음성 나레이션이 있는 컷은 사진 시퀀스가 음성을 합치지 않는다(두 번 들리는 것 방지, 판정은 `reelFinalize.js` `hasVoiceNarration`).
두 번째 방식은 대본에 나레이션이 없는 컷에 임시로 소리를 붙일 때만 쓴다.

주의: 최종본은 대사 없는 컷에서 `cut_NN_nr.mp3` 를 `cut_NN.mp3` 보다 먼저 집는다. TTS 탭은 `cut_NN.mp3` 로 저장하므로, 같은 컷에 옛 `_nr.mp3` 가 남아 있으면 그쪽이 쓰인다.

## 6. 쓰이지 않거나 옛 경로로 남은 것

- `06_publishing/cut_NN_final.mp4` (영상 만들기 "나레이션·효과음 입히기") — 릴스 최종본은 이 파일을 읽지 않는다. 컷 단위로 소리를 미리 들어보는 용도.
- `05_video/output_final/CNN_final.mp4` (전체 일괄 합성) — 옛 경로.
- `06_publishing/ep{N}_raw.mp4` — 롱폼/CapCut 경로의 이어붙임본. 릴스의 완성본은 `07_output/{코드}_final.mp4`.
- `downloads/video/ep{N}/` — 폴더 개편 이전 경로(옛 원본이 남아 있을 수 있음).
